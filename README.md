# Telegram Booking Bot

Telegram-бот для автоматизации записи клиентов к мастерам. Подойдёт салонам красоты, барбершопам, частным специалистам, преподавателям и другим услугам, где клиенту нужно выбрать специалиста и свободное время.

Бот проводит пользователя через весь сценарий записи внутри Telegram, сохраняет данные в PostgreSQL и предоставляет администратору инструменты управления. REST API позволяет подключить сайт, мобильное приложение или CRM к той же базе записей.

## Как это работает

```text
Клиент → выбирает мастера → дату → время → вводит имя → получает подтверждение
                                      ↓
                              PostgreSQL + REST API
                                      ↓
                         Администратор управляет записями
```

## Возможности

### Для клиента

- пошаговая запись через удобные inline-кнопки;
- выбор мастера, даты и времени;
- доступные даты на ближайшие семь дней;
- временные слоты с 09:00 до 19:00;
- защита от двойного бронирования одного слота;
- просмотр своих активных записей командой `/mybookings`;
- отмена записи прямо в Telegram.

### Для администратора

- отдельная панель по команде `/admin`;
- просмотр ближайших записей;
- отмена любой записи;
- добавление новых мастеров;
- удаление мастеров без активных записей;
- доступ к панели только для Telegram ID из настроек.

### Для интеграций

- REST API на FastAPI;
- интерактивная документация Swagger UI;
- получение списка мастеров и записей;
- создание и отмена бронирований;
- проверка состояния сервиса через health endpoint;
- защита операции удаления API-ключом.

## Технологии

- Python 3
- Aiogram 3 — Telegram Bot API и состояния диалога
- FastAPI — REST API и Swagger UI
- PostgreSQL — хранение мастеров и записей
- asyncpg — асинхронная работа с базой данных
- Uvicorn — запуск API-сервера
- python-dotenv — конфигурация через переменные окружения

## Быстрый запуск

### 1. Склонируйте проект

```bash
git clone https://github.com/aiaz-shakirov/telegram-booking-bot.git
cd telegram-booking-bot
```

### 2. Создайте виртуальное окружение

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Для Windows:

```powershell
.venv\Scripts\activate
```

### 3. Настройте окружение

```bash
cp .env.example .env
```

Укажите в `.env`:

- `TELEGRAM_API_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather);
- `DATABASE_*` — параметры подключения к PostgreSQL;
- `ADMIN_IDS` — Telegram ID администраторов через запятую;
- `API_HOST` и `API_PORT` — адрес и порт API;
- `API_KEY` — секретный ключ для защищённых операций API.

Настоящие токены и пароли не должны попадать в Git.

### 4. Запустите приложение

```bash
python main.py
```

Бот и API запускаются одновременно. При первом старте приложение автоматически создаёт таблицы `masters` и `bookings`.

- API: `http://localhost:8000`
- Swagger UI: `http://localhost:8000/docs`
- проверка состояния: `http://localhost:8000/health`

После запуска добавьте первого мастера через команду `/admin`, затем пользователи смогут записываться через `/start`.

## Команды бота

| Команда | Кто использует | Назначение |
| --- | --- | --- |
| `/start` | Клиент | Начать новую запись |
| `/mybookings` | Клиент | Посмотреть и отменить свои записи |
| `/admin` | Администратор | Открыть панель управления |

## REST API

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| `GET` | `/health` | Проверить состояние сервиса |
| `GET` | `/masters` | Получить список мастеров |
| `GET` | `/masters/{master_id}/bookings` | Получить записи мастера |
| `GET` | `/users/{telegram_id}/bookings` | Получить записи клиента |
| `POST` | `/bookings` | Создать запись |
| `DELETE` | `/bookings/{booking_id}` | Отменить запись |

Для `DELETE /bookings/{booking_id}` передайте ключ в заголовке:

```text
X-API-Key: значение_API_KEY_из_env
```
